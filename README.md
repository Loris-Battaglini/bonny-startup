# bonny-startup
progetto start2impact bonny

## Avvio in sviluppo

Installa le dipendenze e avvia il server di sviluppo Vite:

```sh
npm install
npm run dev
```

Apri nel browser l'indirizzo mostrato da Vite (di norma `http://localhost:5173`).
Non aprire `index.html` direttamente né servirlo con un server statico: Vite
trasforma `src/main.ts` in JavaScript e serve correttamente i moduli TypeScript.

Per verificare la build:

```sh
npm run build
```
